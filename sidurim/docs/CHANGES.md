# Changes since the documents froze

This file overrides the frozen `docs/ARCHITECTURE.md` and `docs/GAME_DESIGN.md`: where they differ from it, this file and the code are right.

Those two documents, and `docs/BRIEF.md`, are kept unedited as the record of the original plan. Each row below names the section it
changes, what that section says, what the game does now, and why. Every value was read from the file named in the row on 2026-11-03.
"Owner" in the last column means the owner decided it. Anything else was a deviation made while building, for the reason given. Figures
in the "Why" column are measurements from the work-package and acceptance reports, not values in code.

GAME_DESIGN is "GD" and ARCHITECTURE is "A".
